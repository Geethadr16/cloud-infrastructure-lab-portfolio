# Monitoring Tools

## Overview

This section documents monitoring concepts and capstone activities covered during Cognizant CIS Multicloud training, focusing on SolarWinds and Microsoft System Center Operations Manager (SCOM).

## Tools Covered

* **SolarWinds Orion:** Network device monitoring, alert configuration, and dashboard-based monitoring.
* **SolarWinds Network Traffic Analyzer (NTA):** Network traffic flow and bandwidth analysis.
* **Microsoft SCOM:** Agent deployment, management packs, notifications, reporting, and SLA tracking.

## 1. SolarWinds Orion and NTA

### Installation and Initial Configuration

* Installed SolarWinds Orion on a Windows Server or virtual machine, as documented in the capstone.
* Reviewed initial setup and SQL Server database configuration.
* Accessed the Orion web console.

### Network Device Monitoring

* Added network devices using IP addresses and SNMP/ICMP settings.
* Reviewed device discovery and node monitoring.
* Configured example alert conditions for high CPU usage and device downtime.
* Reviewed email and dashboard notification methods.

### Network Traffic Analysis

* Studied NetFlow configuration for network traffic analysis.
* Reviewed bandwidth usage, top applications, and top traffic-generating devices.

## 2. Microsoft System Center Operations Manager (SCOM)

### Installation and Initial Setup

* Covered SCOM installation on Windows Server.
* Reviewed management server and SQL database configuration.
* Opened the SCOM console and verified the management group dashboard.

### Agent Deployment

* Reviewed the agent discovery workflow.
* Covered deploying monitoring agents to target computers.

### Management Packs

* Covered Windows Server and SQL Server management packs.
* Reviewed custom management pack creation and monitoring rules.

### Notifications and Reporting

* Covered notification configuration, subscriber groups, and alert rules.
* Reviewed availability and performance reports.
* Studied SLA tracking and service availability concepts.

## Key Learning Areas

* Network and server monitoring fundamentals
* Device discovery and monitoring
* Alerts and notifications
* Network traffic and bandwidth analysis
* Monitoring agents and management packs
* Availability reporting and SLA tracking
