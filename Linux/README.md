# Linux Administration Lab

## Overview

This lab documents hands-on Linux administration tasks performed in a virtual lab environment during infrastructure training.

The activities focused on Linux commands, file and directory management, permissions, ownership, package management, and software installation.

## Lab Environment

* Linux Virtual Machine
* Terminal / Command Line Interface
* APT Package Manager

## Skills Practiced

* Directory creation
* File management
* Linux permissions
* Ownership management
* File searching
* Pattern matching
* Package installation
* Package removal

## Assignment 1 - Linux Commands

### Commands Practiced

* mkdir
* chmod
* chown
* grep
* find

### Tasks Performed

* Created personal project directories
* Created subdirectories
* Created text files
* Copied and moved files
* Practiced file permissions

## Assignment 2 - Directory and File Management

### Tasks Performed

* Created nested directory structures
* Created multiple text files
* Copied files between directories
* Moved files using relative and absolute paths
* Deleted files and empty directories

## Assignment 3 - Package Management

### Tasks Performed

* Updated system packages
* Installed software from repositories
* Removed software packages
* Practiced package management using APT

## Key Commands Used

```bash
mkdir
chmod 755
chown
grep
find
sudo apt update
sudo apt install nginx
sudo apt remove nginx
```

## Key Learnings

* Linux file and directory management
* Permission management
* Ownership management
* File searching and filtering
* Package installation and removal
* Basic Linux system administration
