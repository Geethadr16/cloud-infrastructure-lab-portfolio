## Assignment 4 – Network Type Classification

### Network Types Studied

#### LAN (Local Area Network)

- Covers a limited geographical area such as offices or homes.
- Provides high-speed communication within a local environment.

#### WAN (Wide Area Network)

- Connects networks across large geographical areas.
- Used for communication between multiple locations.

#### WLAN (Wireless Local Area Network)

- Uses wireless technology (Wi-Fi) for connectivity.
- Provides mobility and flexible network access.

#### SOHO (Small Office/Home Office)

- Small-scale network supporting home users and small businesses.
- Combines wired and wireless connectivity.

#### MAN (Metropolitan Area Network)

- Connects multiple LANs across a city or metropolitan region.

#### PAN (Personal Area Network)

- Connects personal devices within a short range.

#### CAN (Campus Area Network)

- Connects multiple LANs within a campus or organization.
